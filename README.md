# Bank Management System

## Overview

The Bank Management System is a comprehensive banking application developed as a second-semester academic project under the guidance of **Sir Jimson Mathew**. The project aims to simulate real-world banking operations by providing a secure and user-friendly platform for managing financial transactions and banking services.

## Features

### Account Management

* User registration and account creation
* Secure login system
* Profile management

### Security Features

* Email-based OTP (One-Time Password) verification
* Secure authentication mechanism
* Protected user access and transaction validation

### Banking Services

* Money deposit
* Money withdrawal
* Fund transfer between accounts
* Transaction history and records
* Balance inquiry

### Financial Services

* Loan application and management
* Mobile recharge services
* Utility bill payments
* Account statement generation

## Technologies Used

* Programming Language: Java
* Database Management System
* Email OTP Authentication System
* Object-Oriented Programming Concepts
* Data Structures and Algorithms

## Project Objectives

* To understand the working of modern banking systems.
* To implement secure authentication and authorization mechanisms.
* To gain practical experience in database management and software development.
* To apply object-oriented programming concepts in a real-world application.

## Learning Outcomes

Through this project, we gained experience in:

* Software design and development
* Database integration
* User authentication and security
* Transaction processing
* Team collaboration and project management
